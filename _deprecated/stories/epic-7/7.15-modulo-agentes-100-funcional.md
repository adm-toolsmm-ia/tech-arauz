# Story 7.15 — Módulo Agentes 100% Funcional + Chatbot de Projetos

## Objetivo

Módulo de agentes 100% funcional com foco em agentes tipo chatbot, incluindo um chatbot que consulta o banco de dados (projetos, cronogramas, entregas, requisitos) e frontend alinhado ao backend.

## Acceptance Criteria

- [x] persona, prompt_objective, prompt_instructions, prompt_template persistidos na criação
- [x] CreateAgentDialog com todos os campos do schema (tags, usage_type, persona completa, requirements, output_schema, etc.)
- [x] AgentCockpit exibe owners, requirements, output_schema, validation_rules
- [x] AgentEditSheet com paridade (usageType, showInShortcut, isGlobalChatbot, tags, owners)
- [x] Chat funciona com agente em draft (config lida da tabela agents)
- [x] Chat integrado com run_sql_qa para perguntas sobre projetos (usage_type=chatbot)
- [x] sql_qa com SQL real gerado por LLM e executado no Supabase (RPC execute_readonly_query)
- [ ] Agente "Assistente de Projetos" criável via UI e funcional no chat
- [ ] Quality gates passando (lint, typecheck, test)

## Como criar o Assistente de Projetos via UI

1. Acesse **Agentes** > **Novo Agente**
2. Preencha:
   - **Nome:** Assistente de Projetos
   - **Slug:** assistente-projetos
   - **Tipo de Uso:** Chatbot
   - **Persona:** "Você é um assistente especializado em analisar dados de projetos, cronogramas, entregas e requisitos."
   - **Objetivo:** "Responder perguntas do usuário consultando os dados de projetos no banco e formatando as respostas de forma clara."
   - **Modelo:** gpt-4.1-mini (OpenAI)
   - **Exibir no atalho:** opcional
3. Salve e publique o agente
4. Teste no chat com perguntas como "Quantos projetos ativos temos?" ou "Liste as entregas pendentes"
