## Architecture

- **Search Suggestions:** Client-side filtering of recent + matching projects
- **Debouncing:** 300ms debounce on input change
- **Caching:** localStorage for recent searches (20 items max)
- **Mobile:** Breakpoint-based responsive design (Tailwind sm/md/lg)
- **Accessibility:** ARIA live region for suggestions
