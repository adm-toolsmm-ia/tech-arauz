## Notas Técnicas

### Padrão de ContextPanel

```typescript
<ContextPanel
  isOpen={selectedNucleus !== null}
  onClose={() => setSelectedNucleus(null)}
  title="Núcleo"
  subtitle={selectedNucleus?.name}
  breadcrumb={<Breadcrumb items={[
    { label: "Área", onClick: () => setSelectedNucleus(null) },
    { label: "Núcleo", isCurrent: true }
  ]} />}
  depth={1}
>
  <NucleusCockpit360 nucleus={selectedNucleus} />
</ContextPanel>
```

### Z-Index Stack

```
Global alerts (z-100) — AlertDialog
Form sheets (z-90) — OrgEntityFormSheet
ContextPanel depth 3 (z-80)
ContextPanel depth 2 (z-70)
ContextPanel depth 1 (z-60)
SplitView (z-50)
Main content (z-0)
```

### Escape Key Handling

```typescript
useEffect(() => {
  if (!isOpen) return;

  const handleEscape = (e: KeyboardEvent) => {
    if (e.key === 'Escape') {
      e.preventDefault();
      onClose();
    }
  };

  document.addEventListener('keydown', handleEscape);
  return () => document.removeEventListener('keydown', handleEscape);
}, [isOpen, onClose]);
```

### Sem Backdrop Escuro

```css
/* Importante: Sheet sem overlay escuro */
[data-state="open"] .sheet-overlay {
  background-color: transparent;
  pointer-events: none;
}
```


## Observações

ContextPanel é **stateless** — apenas renderiza children recebido via props. State (isOpen, onClose) fica no content pai (AreasContent, ProcessosContent, etc).

Padrão de breadcrumb permite navegação rápida sem fechar tudo. Exemplo:
- Usuário em: Area → Nucleus → Process → Routine
- Clica "Nucleus" no breadcrumb
- Fecha painéis Process e Routine, volta para ContextPanel de Nucleus

Sheet Shadcn já suporta Sheet.Content — usamos isso como container principal.
