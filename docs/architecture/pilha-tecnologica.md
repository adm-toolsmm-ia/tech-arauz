> Versão PT-BR de `docs/framework/tech-stack.md` (fallback AIOS).
> Para detalhes completos, consulte [tech-stack.md](../framework/tech-stack.md).

## Stack Principal

- **Frontend**: Next.js 14 (App Router) + React 18 + TypeScript 5.5
- **UI**: Shadcn/ui (Radix UI + Tailwind CSS)
- **Estado**: TanStack Query 5 (server) + Zustand 4.5 (client)
- **Backend**: Supabase (PostgreSQL + Auth + RLS)
- **Deploy**: Vercel
- **Integração ERP**: Espaider via WCF API (read-only)

## Bibliotecas Auxiliares

- **Gráficos**: Recharts
- **Rich Text**: TipTap
- **Datas**: date-fns
- **Validação**: Zod
- **Drag & Drop**: dnd-kit
- **Testes**: Vitest
