|-------|----------|-------|

| `description` | No | Max 1000 chars |

| Field | Required | Rules |

## 🔐 Authorization Context (Server Actions)

All server actions receive implicit authorization context:

```typescript
// Available in all server action functions
const authContext = {
  user_id: string; // From auth.uid()
  tenant_id: string; // From user profile
  roles: string[]; // User's roles in organization
  permissions: string[]; // Derived from roles
};
```

### Permission Check Pattern

```typescript
async function createActivityAction(data: OrgActivity) {
  // RLS enforces tenant_id isolation
  // Server action validates permissions via role-based checks
  if (!userHasPermission('write:activities')) {
    throw new Error('Unauthorized');
  }

  // Create activity (RLS ensures tenant_id match)
  return await supabase
    .from('org_activities')
    .insert({ ...data, tenant_id: authContext.tenant_id });
}
```
