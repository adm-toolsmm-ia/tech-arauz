## Objetivo
Enhance chatbot with persistent conversation history, sidebar conversation list, conversation save/load functionality, and multi-conversation management. Support conversation search and tagging.

**Status**: ✅ IMPLEMENTED IN v0.2.2 | Documentation-only story

---

## Critérios de Aceitação

- [ ] AC-001: Conversation history database
  - [ ] Store conversations in `chat_conversations` table
  - [ ] Fields: id, user_id, agent_id, title, created_at, updated_at
  - [ ] RLS policy: user can only access own conversations
  - [ ] Indexed on user_id + created_at for fast queries

- [ ] AC-002: Conversation persistence
  - [ ] Save conversation on send message
  - [ ] Load conversation history on re-open
  - [ ] Update conversation title (auto-generated or user-specified)
  - [ ] Delete old conversations (cleanup script)

- [ ] AC-003: Conversation sidebar
  - [ ] List recent conversations (last 10)
  - [ ] Click to load conversation
  - [ ] Search conversations by title
  - [ ] Delete conversation action

- [ ] AC-004: Multi-conversation support
  - [ ] New conversation button
  - [ ] Switch between conversations without losing history
  - [ ] "New chat" tab prominent

- [ ] AC-005: Export & backup
  - [ ] Export conversation as JSON
  - [ ] Export conversation as PDF
  - [ ] Batch export multiple conversations

- [ ] AC-006: Test coverage >90%
  - [ ] Unit: Conversation save/load logic
  - [ ] Integration: Chat messages persist to DB
  - [ ] Integration: RLS prevents cross-user access
