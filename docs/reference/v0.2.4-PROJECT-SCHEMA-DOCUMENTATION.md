## 📊 Database Schema (EPIC 11 — Organizational Enrichment & BPM Mastery)

### Organizational Hierarchy

#### 1. **org_areas** — Organizational Areas
Nível 1 da hierarquia: Áreas (ex: "Recuperação de Crédito", "Trabalhista")

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `tenant_id` | UUID | Tenant isolation (RLS) |
| `name` | TEXT | Area name (e.g., "Recuperação de Crédito") |
| `description` | TEXT | Detailed description |
| `objective` | TEXT | Strategic objective |
| `responsible_roles` | TEXT[] | Array of roles responsible |
| `documentation` | JSONB | {procedures, instructions, best_practices, common_errors} |
| `created_at` | TIMESTAMPTZ | Creation timestamp |
| `updated_at` | TIMESTAMPTZ | Last update timestamp |

**Indexes:** `idx_org_areas_tenant`, `idx_org_areas_name`
**RLS:** Via tenant_id (all operations tenant-isolated)

---

#### 2. **org_nuclei** — Organizational Nuclei (Sub-areas)
Nível 2 da hierarquia: Núcleos (ex: "Análise de Risco", "Ações Judiciais")

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `tenant_id` | UUID | Tenant isolation (RLS) |
| `area_id` | UUID | Parent area (FK) |
| `name` | TEXT | Nucleus name |
| `description` | TEXT | Detailed description |
| `objective` | TEXT | Strategic objective |
| `responsible_roles` | TEXT[] | Roles responsible |
| `documentation` | JSONB | Nucleus documentation |
| `created_at` | TIMESTAMPTZ | Creation timestamp |
| `updated_at` | TIMESTAMPTZ | Last update timestamp |

**Relationship:** `area_id` → `org_areas(id)` (ON DELETE CASCADE)
**Indexes:** `idx_org_nuclei_area`, `idx_org_nuclei_tenant`

#### 3. **org_processes** — Organizational Processes
Nível 3 da hierarquia: Processos (ex: "Análise Jurídica", "Encaminhamento para Juízo")

| Field | Type | Description |
|-------|------|-------------|
| `id` | UUID | Primary key |
| `tenant_id` | UUID | Tenant isolation (RLS) |
| `area_id` | UUID | Parent area (FK, nullable) |
| `nucleus_id` | UUID | Parent nucleus (FK, nullable) |
| `name` | TEXT | Process name |
| `description` | TEXT | Detailed description |
| `objective` | TEXT | Strategic objective |
| `inputs` | JSONB | Array of {name, type, description} |
| `outputs` | JSONB | Array of {name, type, description} |
| `responsible_roles` | TEXT[] | Roles responsible |
| `risks` | TEXT[] | Known risks |
| `impacts` | TEXT[] | Potential impacts |
| `documentation` | JSONB | Process documentation |
| `created_at` | TIMESTAMPTZ | Creation timestamp |
| `updated_at` | TIMESTAMPTZ | Last update timestamp |

**Relationships:**
- `area_id` → `org_areas(id)` (nullable, ON DELETE SET NULL)
- `nucleus_id` → `org_nuclei(id)` (nullable, ON DELETE SET NULL)

**Indexes:** `idx_org_processes_area`, `idx_org_processes_nucleus`, `idx_org_processes_tenant`
