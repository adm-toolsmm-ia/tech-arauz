## Migration 067: Activity-System M:M Junction

**File:** `supabase/migrations/067_create_activity_systems_junction.sql`
**Story:** 11.2 (Activity-System Integration)
**Date:** 2026-03-28

### Changes

#### New Table: `org_activity_systems`

**Purpose:** Track which systems are used in each activity + usage context

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `activity_id` | UUID | FK → org_activities.id (CASCADE) | Activity |
| `system_id` | UUID | FK → org_systems.id (CASCADE) | System |
| `tenant_id` | UUID | FK → tenants.id (CASCADE) | Tenant isolation |
| `usage_context` | TEXT | — | "data_entry" \| "lookup" \| "reporting" |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Timestamp |
| `updated_at` | TIMESTAMPTZ | DEFAULT NOW() | Timestamp |
| **Primary Key** | — | (activity_id, system_id) | M:M unique constraint |

**Schema:**
```sql
CREATE TABLE public.org_activity_systems (
  activity_id UUID NOT NULL REFERENCES public.org_activities(id) ON DELETE CASCADE,
  system_id UUID NOT NULL REFERENCES public.org_systems(id) ON DELETE CASCADE,
  tenant_id UUID NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  usage_context TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  PRIMARY KEY (activity_id, system_id)
);
```

### Indexes Created

| Index | Columns | Purpose |
|-------|---------|---------|
| `idx_org_activity_systems_activity` | activity_id | List systems for activity |
| `idx_org_activity_systems_system` | system_id | Find activities using system |
| `idx_org_activity_systems_tenant` | tenant_id | Tenant isolation filtering |

**Query Examples:**
```sql
-- Find all systems used in activity
SELECT * FROM org_activity_systems
WHERE activity_id = $1 AND tenant_id = $2;

-- Find all activities using a system
SELECT * FROM org_activity_systems
WHERE system_id = $1 AND tenant_id = $2;
```

### Cascade Behavior

- **Delete Activity:** All org_activity_systems rows deleted automatically
- **Delete System:** All org_activity_systems rows deleted automatically
- **Delete Tenant:** All org_activity_systems rows deleted automatically

### RLS Impact

✅ **No new RLS policies needed** — Tenant isolation via `tenant_id` FK + existing policies.

### Rollback

```sql
DROP INDEX IF EXISTS idx_org_activity_systems_system;
DROP INDEX IF EXISTS idx_org_activity_systems_activity;
DROP INDEX IF EXISTS idx_org_activity_systems_tenant;
DROP TABLE IF EXISTS public.org_activity_systems;
```

### Migration Duration

- **Execution:** ~50ms (create table + 3 indexes)
- **Data Lock:** None (new table)
- **Risk Level:** 🟢 LOW

## Migration 068: Process SLAs & Metrics

**File:** `supabase/migrations/068_create_process_slas_and_metrics.sql`
**Story:** 11.3 (Process SLAs & Metrics Dashboard)
**Date:** 2026-03-28

### Changes

#### New Table 1: `org_process_slas`

**Purpose:** Define Service Level Agreements (SLA targets) for processes

| Column | Type | Default | Notes |
|--------|------|---------|-------|
| `id` | UUID | gen_random_uuid() | Primary key |
| `tenant_id` | UUID | — | FK → tenants.id (CASCADE) |
| `process_id` | UUID | — | FK → org_processes.id (CASCADE) |
| `metric_name` | TEXT | — | "completion_time", "quality_score", etc. |
| `target_duration_days` | INTEGER | — | SLA target in days |
| `warning_threshold_pct` | DECIMAL(5,2) | 80.00 | % of SLA to trigger warning |
| `critical_threshold_pct` | DECIMAL(5,2) | 95.00 | % of SLA to trigger critical |
| `created_at` | TIMESTAMPTZ | NOW() | Timestamp |
| `updated_at` | TIMESTAMPTZ | NOW() | Timestamp |
| **Unique** | — | (tenant_id, process_id, metric_name) | One SLA per metric |

**Schema:**
```sql
CREATE TABLE public.org_process_slas (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  process_id UUID NOT NULL REFERENCES public.org_processes(id) ON DELETE CASCADE,
  metric_name TEXT NOT NULL,
  target_duration_days INTEGER NOT NULL,
  warning_threshold_pct DECIMAL(5,2) DEFAULT 80.00,
  critical_threshold_pct DECIMAL(5,2) DEFAULT 95.00,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(tenant_id, process_id, metric_name)
);
```

#### New Table 2: `org_process_metrics`

**Purpose:** Store observed metrics + compliance tracking (aggregated per period)

| Column | Type | Default | Notes |
|--------|------|---------|-------|
| `id` | UUID | gen_random_uuid() | Primary key |
| `tenant_id` | UUID | — | FK → tenants.id (CASCADE) |
| `process_id` | UUID | — | FK → org_processes.id (CASCADE) |
| `period_start` | DATE | — | Period start date |
| `period_end` | DATE | — | Period end date |
| `metric_name` | TEXT | — | Must match org_process_slas.metric_name |
| `avg_duration_days` | DECIMAL(10,2) | NULL | Average duration for period |
| `compliance_pct` | DECIMAL(5,2) | NULL | % instances meeting SLA (0-100) |
| `instances_count` | INTEGER | 0 | Total instances in period |
| `created_at` | TIMESTAMPTZ | NOW() | Timestamp |
| `updated_at` | TIMESTAMPTZ | NOW() | Timestamp |
| **Unique** | — | (tenant_id, process_id, metric_name, period_start, period_end) | One metric per period |

**Schema:**
```sql
CREATE TABLE public.org_process_metrics (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  process_id UUID NOT NULL REFERENCES public.org_processes(id) ON DELETE CASCADE,
  period_start DATE NOT NULL,
  period_end DATE NOT NULL,
  metric_name TEXT NOT NULL,
  avg_duration_days DECIMAL(10,2),
  compliance_pct DECIMAL(5,2),
  instances_count INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(tenant_id, process_id, metric_name, period_start, period_end)
);
```

### Indexes Created

| Table | Index | Columns | Purpose |
|-------|-------|---------|---------|
| org_process_slas | idx_org_process_slas_tenant | tenant_id | Tenant filtering |
| org_process_slas | idx_org_process_slas_process | process_id | SLAs for process |
| org_process_metrics | idx_org_process_metrics_tenant | tenant_id | Tenant filtering |
| org_process_metrics | idx_org_process_metrics_process | process_id | Metrics for process |
| org_process_metrics | idx_org_process_metrics_period | (period_start, period_end) | Range queries |

### Query Examples

```sql
-- Get SLA for a process metric
SELECT * FROM org_process_slas
WHERE process_id = $1 AND metric_name = $2 AND tenant_id = $3;

-- Get metrics for a process in a time range
SELECT * FROM org_process_metrics
WHERE process_id = $1
  AND period_start >= $2
  AND period_end <= $3
  AND tenant_id = $4;

-- Calculate compliance status
SELECT
  sla.metric_name,
  sla.target_duration_days,
  metrics.avg_duration_days,
  metrics.compliance_pct,
  CASE
    WHEN metrics.compliance_pct >= 100 THEN 'compliant'
    WHEN metrics.compliance_pct >= 80 THEN 'warning'
    ELSE 'critical'
  END as status
FROM org_process_slas sla
LEFT JOIN org_process_metrics metrics
  ON sla.process_id = metrics.process_id
  AND sla.metric_name = metrics.metric_name
WHERE sla.process_id = $1 AND sla.tenant_id = $2;
```

### RLS Impact

✅ **No new RLS policies needed** — Tenant isolation via `tenant_id` FK.

### Rollback

```sql

DROP INDEX IF EXISTS idx_org_process_metrics_process;
DROP INDEX IF EXISTS idx_org_process_metrics_tenant;
DROP TABLE IF EXISTS public.org_process_metrics;

DROP INDEX IF EXISTS idx_org_process_slas_process;
DROP INDEX IF EXISTS idx_org_process_slas_tenant;
DROP TABLE IF EXISTS public.org_process_slas;
```

### Migration Duration

- **Execution:** ~100ms (2 tables + 5 indexes)
