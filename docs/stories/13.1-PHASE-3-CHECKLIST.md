## 🎨 Dark Mode Color Palette

### Alert/Status Colors

```tsx
// Dirty state (unsaved changes)
bg-yellow-50 dark:bg-yellow-950
border-yellow-200 dark:border-yellow-800
text-yellow-800 dark:text-yellow-200

// Error state
bg-red-50 dark:bg-red-950
border-red-200 dark:border-red-800
text-red-500 dark:text-red-400

// Success state (optional)
bg-green-50 dark:bg-green-950
border-green-200 dark:border-green-800
text-green-800 dark:text-green-200

// Info state (optional)
bg-blue-50 dark:bg-blue-950
border-blue-200 dark:border-blue-800
text-blue-800 dark:text-blue-200
```

### Apply to All Cards/Alerts:
```tsx
<Card className="m-4 border-yellow-200 bg-yellow-50 dark:border-yellow-800 dark:bg-yellow-950">
  <CardContent className="pt-4">
    <p className="text-sm text-yellow-800 dark:text-yellow-200">Message</p>
  </CardContent>
</Card>
```

## 🔧 Common Implementation Patterns

### Label Association
```tsx
<Label htmlFor="sla_type">Tipo de SLA *</Label>
<Select>
  <SelectTrigger id="sla_type">
    <SelectValue />
  </SelectTrigger>
</Select>
```

### Error Handling
```tsx
<Input
  id="target_value"
  aria-invalid={!!errors.target_value}
  aria-describedby={errors.target_value ? 'target_value-error' : undefined}
  className={errors.target_value ? 'border-red-500' : ''}
/>
{errors.target_value && (
  <p id="target_value-error" className="text-xs text-red-500 mt-1" role="alert">
    {errors.target_value}
  </p>
)}
```

### Loading State
```tsx
<Button disabled={isSaving} className="gap-2">
  {isSaving ? (
    <>
      <Loader2 className="w-4 h-4 animate-spin" />
      Salvando...
    </>
  ) : (
    <>
      <Save className="w-4 h-4" />
      Salvar
    </>
  )}
</Button>
```

### Toast Notification
```tsx
import { toast } from 'sonner';

// Success
toast.success('✅ SLA criada com sucesso!');

// Error
toast.error('❌ Erro ao criar SLA');
```

### Keyboard Navigation
```tsx
// Handled by shadcn/ui components automatically:
// - Tab: move between inputs
// - Shift+Tab: move backwards
// - Enter: submit form
// - Escape: close modal
```

## 🚨 Critical Don'ts

❌ **DON'T:**
- Skip labels (accessibility blocker)
- Use `placeholder` instead of `<Label>`
- Forget dark mode variants
- Add focus ring inline (let CSS handle it)
- Make buttons icon-only without aria-label
- Disable inputs without reason
- Trap focus outside modal
- Skip error messages

✅ **DO:**
- Add htmlFor to labels
- Use `<Label>` component
- Add `dark:` classes to all colors
- Rely on CSS focus-visible
- Add aria-label to icon buttons
- Show loading state when disabled
- Let Sheet component handle focus
- Show clear error messages with role="alert"
