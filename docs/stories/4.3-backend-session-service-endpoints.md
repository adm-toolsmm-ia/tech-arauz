## Objetivo

Criar session service para gerenciar contexto conversacional (histórico de mensagens, persistência em Supabase), e 3 endpoints REST para iniciar/retomar chat, listar sessões, e recuperar histórico de mensagens.

---

## Como Usuário

Como desenvolvedor de frontend,
quero ter uma API de chat com persistência de sessões e histórico de mensagens,
para que eu possa construir uma UI conversacional onde usuários podem manter múltiplas sessões com agentes, e cada sessão recupera o histórico anterior.

---

## Contexto

**Situação atual:**
- Story 4.2 criou factory de LLM providers e SQL validator
- Não há service para gerenciar sessões de chat
- Não há endpoints REST para chat

**Mudança necessária:**
- Service em `services/ai/app/services/session_service.py` que:
  - Cria/recupera sessão (agent_sessions table via Supabase)
  - Carrega histórico de mensagens (últimas N para contexto LCEL)
  - Persiste mensagens (user + assistant) em agent_messages
  - Atualiza usage diário (agent_usage_daily com incremento)
- 3 endpoints em `services/ai/app/api/routes.py`:
  - `POST /api/agents/{agent_id}/chat` — enviar mensagem, receber resposta
  - `GET /api/agents/{agent_id}/sessions` — listar sessões do usuário
  - `GET /api/agents/{agent_id}/sessions/{session_id}/messages` — recuperar histórico

## Critérios de Aceite

### Session Service (services/session_service.py)

- [ ] Função `get_or_create_session(agent_id: str, session_id: Optional[str], tenant_id: str, user_id: str) → dict`
  - Se `session_id` é None → criar nova session (agent_sessions)
  - Se `session_id` é provided → recuperar session existente
  - Retorna dict com: `{ id, agent_id, user_id, tenant_id, started_at, status, token_usage }`
  - Valida que session pertence ao tenant/user (segurança)
  - Levanta `SessionServiceError` se não encontrada ou acesso negado

- [ ] Função `load_message_history(session_id: str, limit: int = 10) → list[dict]`
  - Retorna últimas N mensagens da session (para contexto LLM)
  - Cada message: `{ id, role, content, created_at, tokens_used }`
  - Ordena por created_at ASC (mais antigos primeiro, para LCEL context)
  - Retorna lista vazia se session não tem messages

- [ ] Função `persist_turn(session_id: str, tenant_id: str, user_msg: str, assistant_msg: str, run_id: str, metadata: Optional[dict]) → tuple[str, str]`
  - Cria dois registros em agent_messages:
    1. User message: `{ id, session_id, tenant_id, role='user', content=user_msg, ... }`
    2. Assistant message: `{ id, session_id, tenant_id, role='assistant', content=assistant_msg, ... }`
  - Metadata armazenado em JSONB (run_id, trace_url, tokens, cost_usd, etc.)
  - Retorna tuple: `(user_message_id, assistant_message_id)`
  - Levanta `SessionServiceError` se INSERT falha

- [ ] Função `update_usage_daily(agent_id: str, tenant_id: str, run_result: dict) → None`
  - UPSERT em agent_usage_daily: `(tenant_id, agent_id, date) = (X, Y, TODAY)`
  - Incrementa: `messages_count++`, `cost_total_usd += run_result.cost_usd`
  - Calcula: `avg_latency_ms`, `success_rate_pct`
  - Usa ON CONFLICT para idempotência
  - Silenciosamente falha (loga erro) se não conseguir atualizar

- [ ] Classe `SessionServiceError(Exception)`
  - Herda de Exception
  - Armazena: error_code (not_found, access_denied, database_error), message

- [ ] Imports:
  - `from supabase import AsyncClient` (passed in as param)
  - `import logging`
  - `from datetime import datetime`

### REST Endpoints (routes.py)

- [ ] Endpoint: `POST /api/agents/{agent_id}/chat`
  - **Request:**
    ```json
    {
      "session_id": "uuid or null",
      "message": "user question",
      "config": { "temperature": 0.7 }  // optional
    }
    ```
  - **Response (200):**
    ```json
    {
      "session_id": "uuid",
      "message_id": "uuid",
      "answer": "assistant response text",
      "sql_query": "SELECT ...",  // optional if SQL was generated
      "row_count": 42,  // optional
      "tokens_used": 150,
      "cost_usd": 0.0045,
      "trace_url": "https://smith.langchain.com/...",  // optional
      "duration_ms": 2340
    }
    ```
  - **Error responses:**
    - 401: Missing/invalid Bearer token → "Missing or invalid Authorization header"
    - 404: Agent not found → "Agent {agent_id} not found"
    - 400: Invalid request → "message field is required"
    - 429: Budget exceeded → `{ error: "budget_exceeded", ... }`
  - **Auth:** JWT Bearer token via `get_token_data(request)` (padrão existente)
  - **Dependencies:**
    - `get_token_data(request)` → dict with user_id, tenant_id
    - `get_supabase_client(request)` → AsyncClient
    - `session_service.get_or_create_session(...)` → cria/recupera session
    - `session_service.load_message_history(...)` → contexto para LCEL
    - `session_service.persist_turn(...)` → salva user + assistant messages
    - `session_service.update_usage_daily(...)` → atualiza metrics
    - (Story 4.4 fornecerá LCEL chain que retorna answer, sql_query, etc.)

- [ ] Endpoint: `GET /api/agents/{agent_id}/sessions`
  - **Query params:**
    - `page` (default: 1) — paginação
    - `page_size` (default: 10, max: 50) — itens por página
  - **Response (200):**
    ```json
    {
      "sessions": [
        {
          "id": "uuid",
          "agent_id": "uuid",
          "user_id": "uuid",
          "tenant_id": "uuid",
          "started_at": "2026-03-01T...",
          "status": "active",
          "message_count": 5,
          "last_message_at": "2026-03-01T..."
        }
      ],
      "total": 42,
      "page": 1,
      "page_size": 10,
      "has_next": true
    }
    ```
  - **Error responses:**
    - 401: Sem auth
    - 404: Agent not found
  - **Auth:** JWT Bearer token
  - **Query:** SELECT from agent_sessions WHERE tenant_id = X AND agent_id = Y ORDER BY created_at DESC

- [ ] Endpoint: `GET /api/agents/{agent_id}/sessions/{session_id}/messages`
  - **Query params:**
    - `page` (default: 1)
    - `page_size` (default: 20, max: 100)
  - **Response (200):**
    ```json
    {
      "messages": [
        {
          "id": "uuid",
          "session_id": "uuid",
          "role": "user|assistant",
          "content": "message text",
          "created_at": "2026-03-01T...",
          "tokens_used": 50,
          "metadata": {}
        }
      ],
      "total": 15,
      "page": 1,
      "page_size": 20,
      "has_next": false
    }
    ```
  - **Error responses:**
    - 401: Sem auth
    - 404: Agent not found OR session not found
  - **Auth:** JWT Bearer token (valida que session pertence ao tenant do user)
  - **Query:** SELECT from agent_messages WHERE session_id = X AND tenant_id = Y

def test_get_or_create_session_new():
    """Test creating a new session."""
    session = await session_service.get_or_create_session(
        agent_id="agent-1",
        session_id=None,
        tenant_id="tenant-1",
        user_id="user-1",
    )
    assert session["agent_id"] == "agent-1"
    assert session["tenant_id"] == "tenant-1"
    assert session["status"] == "active"

def test_get_or_create_session_existing():
    """Test retrieving an existing session."""
    session_id = "existing-session-uuid"
    session = await session_service.get_or_create_session(
        agent_id="agent-1",
        session_id=session_id,
        tenant_id="tenant-1",
        user_id="user-1",
    )
    assert session["id"] == session_id

def test_load_message_history():
    """Test loading message history."""
    messages = await session_service.load_message_history(
        session_id="session-1",
        limit=10,
    )
    assert isinstance(messages, list)
    if messages:
        assert "role" in messages[0]
        assert "content" in messages[0]

def test_persist_turn():
    """Test persisting a user/assistant message pair."""
    user_id, asst_id = await session_service.persist_turn(
        session_id="session-1",
        tenant_id="tenant-1",
        user_msg="Hello",
        assistant_msg="Hi there!",
        run_id="run-123",
        metadata={"tokens": 50},
    )

    assert asst_id is not None
