## Objetivo

Criar interface de chat frontend que consome endpoints backend (POST /api/agents/[id]/chat, GET /api/agents/[id]/sessions), com componentes de bolha de chat, persistência de sessões, histórico paginado, e integração nos módulos AgentCockpit e agent-edit-content.

---

## Como Usuário

Como usuário do portal Tech Arauz,
quero testar um agente AI clicando em "Testar Chat" na página de agentes,
para que eu possa fazer perguntas em linguagem natural e receber respostas com dados reais, histórico persistente e visibilidade de custos/tokens.

## Critérios de Aceite

### 1. Frontend Proxy Routes

- [ ] **Criado `src/app/api/agents/[id]/chat/route.ts`**
  - Padrão idêntico a `src/app/api/agents/[id]/route.ts` (getUser → getSession → forward Bearer)
  - Método: POST
  - Request body: `{ session_id?: string, message: string }`
  - Response: Forward resposta do FastAPI diretamente
  - Error handling: Retorna 401 (Unauthorized), 400 (Bad Request), 500 (Server Error) com erro mensagem

- [ ] **Criado `src/app/api/agents/[id]/sessions/route.ts`**
  - Método GET: Retorna lista de sessões com paginação padrão (limit=10, offset=0)
  - Método POST: Cria nova sessão (retorna session_id + created_at)
  - Padrão: Mesmo fluxo getUser → getSession → forward Bearer
  - Query params: `?limit=10&offset=0` para GET
  - Response GET: `{ sessions: [...], total: number }`
  - Response POST: `{ session_id: string, created_at: timestamp }`

### 2. Componente ChatBubble

- [ ] **Criado `src/components/agents/ChatBubble.tsx`**
  - Props: `{ role: 'user' | 'assistant', content: string, tokens?: number, cost?: number, sql?: string }`
  - User bubble: Alinhado à direita, fundo azul (bg-blue-600), texto branco
  - Assistant bubble: Alinhado à esquerda, fundo muted (bg-muted), texto escuro
  - Footer com metadata (condicional):
    - Mostrado se `tokens` ou `cost` ou `sql` fornecido
    - Exibe: "Tokens: X | Cost: $Y.YY"
    - Se `sql` fornecido: `<details>` com badge "SQL" colapsável, mostra SQL dentro
  - Markdown rendering (se aplicável): Converte `content` em HTML se houver markdown
  - Responsivo: Text wrapping em mobile, max-width apropriada

### 3. Componente ChatContent

- [ ] **Criado `src/app/agentes/[id]/chat/chat-content.tsx`**
  - Props: `{ agentId: string, initialSessionId?: string, initialMessages?: any[] }`
  - `useState` para lista de mensagens (inicializa com `initialMessages` se fornecido)
  - `useRef` para referência do container de scroll
  - `useEffect` para auto-scroll ao fim da lista após novo turno
  - Input: Campo de texto + botão "Enviar"
  - Comportamento:
    - User input: Renderizado imediatamente (optimistic update)
    - Após envio: `fetch POST /api/agents/[agentId]/chat` com `{ session_id, message }`
    - Enquanto aguarda: Skeleton loader no lugar da resposta
    - Resposta: Renderiza ChatBubble com dados do backend (answer, tokens, cost, sql)
    - Erro: `toast.error()` (usar sonner do projeto, padrão existente)
  - Botão "New Chat": Cria novo `session_id` via POST `/api/agents/[agentId]/sessions`, limpa estado local
  - Sem TanStack Query: Usar `fetch` + `await` simples

### 4. Página Chat

- [ ] **Criado `src/app/agentes/[id]/chat/page.tsx`**
  - Server component
  - Padrão: Tipo `Page({ params, searchParams })`
  - Lógica:
    1. Extrai `agentId` de `params.id`
    2. Busca initial session (GET `/api/agents/[agentId]/sessions?limit=1`) ou recebe `sessionId` de query param
    3. Se session existe: Busca últimas 10 mensagens (GET `/api/agents/[agentId]/sessions/[sessionId]/messages`)
    4. Passa `initialSessionId` e `initialMessages` para `<ChatContent />`
  - Error handling: Se agent não existe ou não publicado, redireciona para `/agentes`
  - Layout: Sidebar (se houver), main content com ChatContent, footer com info

### 5. Modificações AgentCockpit

- [ ] **Modificado `src/components/agents/AgentCockpit.tsx`**
  - Adiciona botão "Testar Chat" no header/toolbar
  - Visibilidade: Somente se `agent.status === 'published'`
  - Comportamento: Link para `/agentes/{agent.id}/chat` (usar `next/link` ou `useRouter().push()`)
  - Estilo: Botão primário (cor azul, consistente com design system)
  - Posicionamento: Próximo a outros botões de ação (editar, etc.)

### 6. Modificações agent-edit-content

- [ ] **Modificado `src/app/agentes/[id]/agent-edit-content.tsx`**

  - Visibilidade: Somente se `agent.status === 'published'`
  - Comportamento: Mesmo que AgentCockpit (link para `/agentes/{id}/chat`)
  - Posicionamento: Consistente com layout existente

## Referências Técnicas

**Padrão de proxy route:**
- Arquivo: `src/app/api/agents/[id]/route.ts`
- Pattern: `getUser() → getSession() → forward com Bearer token`
- Response: Forward resposta JSON do backend diretamente

**Padrão de componente com estado:**
- Arquivo: `src/app/agentes/[id]/agent-edit-content.tsx`
- Pattern: `useState` para local state, múltiplos `useEffect` para sincronização
- Exemplo: Tabs, skeleton, loading states

**Padrão de chat bubble similar:**
- Arquivo: `src/components/projects/ProjectKanbanCard.tsx`
- Inspiração: Layout, styling, metadata display

**Padrão de fetch data:**
- Arquivo: `src/app/agentes/agentes-content.tsx`
- Pattern: `fetch` + `await`, sem TanStack Query para operações simples
- Error handling: `toast.error()` do sonner

**Padrão de server component + client component:**
- Layout: Server `page.tsx` carrega dados, passa props para client `chat-content.tsx`
- Divisão: Data loading server-side, interação client-side

### test_chat_bubble.tsx
```typescript
describe('ChatBubble', () => {
  it('renders user message aligned right with blue background', () => {
    render(<ChatBubble role="user" content="Hello" />);
    expect(screen.getByText('Hello')).toHaveClass('text-right');
  });

  it('renders assistant message aligned left with muted background', () => {
    render(<ChatBubble role="assistant" content="Hi there" />);
    expect(screen.getByText('Hi there')).toHaveClass('text-left');
  });

  it('displays tokens and cost in footer when provided', () => {
    render(
      <ChatBubble
        role="assistant"
        content="Response"
        tokens={150}
        cost={0.0015}
      />
    );
    expect(screen.getByText(/Tokens: 150/)).toBeInTheDocument();
    expect(screen.getByText(/Cost: \$0.00/)).toBeInTheDocument();
  });

  it('shows SQL details in collapsible details element', () => {
    render(
      <ChatBubble
        role="assistant"
        content="Response"
        sql="SELECT * FROM projects"
      />
    );
    const details = screen.getByRole('region');
    expect(details).toBeInTheDocument();
    // Initially collapsed
    expect(screen.queryByText('SELECT * FROM projects')).not.toBeVisible();
  });
});
```

### test_chat_content.tsx
```typescript
describe('ChatContent', () => {
  it('initializes with provided messages', () => {
    const messages = [
      { role: 'user', content: 'Hello' },
      { role: 'assistant', content: 'Hi' },
    ];
    render(
      <ChatContent agentId="agent-1" initialMessages={messages} />
    );
    expect(screen.getByText('Hello')).toBeInTheDocument();
    expect(screen.getByText('Hi')).toBeInTheDocument();
  });

  it('sends message and displays optimistic update', async () => {
    render(<ChatContent agentId="agent-1" />);
    const input = screen.getByRole('textbox');
    await userEvent.type(input, 'Test message');
    await userEvent.click(screen.getByRole('button', { name: /Send/i }));
    expect(screen.getByText('Test message')).toBeInTheDocument();
  });

  it('displays skeleton while waiting for response', async () => {
    // Mock fetch to delay
    global.fetch = jest.fn(() => new Promise(() => {})); // Never resolves
    render(<ChatContent agentId="agent-1" />);
    await userEvent.type(screen.getByRole('textbox'), 'Query');
    await userEvent.click(screen.getByRole('button', { name: /Send/i }));
    expect(screen.getByTestId('skeleton-loader')).toBeInTheDocument();
  });

  it('displays error toast on fetch failure', async () => {
    global.fetch = jest.fn(() =>
      Promise.reject(new Error('Network error'))
    );
    render(<ChatContent agentId="agent-1" />);
    await userEvent.type(screen.getByRole('textbox'), 'Query');
    await userEvent.click(screen.getByRole('button', { name: /Send/i }));
    await waitFor(() => {
      expect(toast.error).toHaveBeenCalledWith(expect.stringContaining('Error'));
    });
  });

  it('creates new session on "New Chat" button', async () => {
    global.fetch = jest.fn((url) => {
      if (url.includes('/sessions')) {
        return Promise.resolve({
          ok: true,
          json: () => Promise.resolve({ session_id: 'new-session' }),
        });
      }
    });
    render(<ChatContent agentId="agent-1" />);
    await userEvent.click(screen.getByRole('button', { name: /New Chat/i }));
    await waitFor(() => {
      expect(screen.queryByText(/previous message/i)).not.toBeInTheDocument();
    });
  });

  it('auto-scrolls to bottom after new message', async () => {
    const scrollIntoViewMock = jest.fn();
    HTMLElement.prototype.scrollIntoView = scrollIntoViewMock;

    render(<ChatContent agentId="agent-1" />);
    // Add message
    await userEvent.type(screen.getByRole('textbox'), 'Test');
    await userEvent.click(screen.getByRole('button', { name: /Send/i }));

    await waitFor(() => {
      expect(scrollIntoViewMock).toHaveBeenCalled();
    });
  });
});
```
