  T0: Inicia 3 chamadas em paralelo

      ├─ Read 2: Iniciado ✅

  T1 (~50ms): Read 1 completa
      └─ ✅ Sucesso! Arquivo encontrado

  T2 (~100ms): Read 2 falha
      ├─ ❌ ERRO: Arquivo não existe
      ├─ Sistema marca promise como rejeitada
      └─ ⚠️ Propaga falha para siblings

  T3 (~150ms): Bash tenta completar
      ├─ Vê que Read 2 falhou
      ├─ Não pode continuar
      └─ ⚠️ "SIBLING TOOL CALL ERRORED"
         └─ Nota: Não é erro de Bash!
            É erro de cascata de Read 2


═════════════════════════════════════════════════════════════════════════════
  VISUALIZAÇÃO: Promise.all Comportamento
═════════════════════════════════════════════════════════════════════════════

Padrão JavaScript Padrão (interno):

┌─────────────────────────────────────────────────────────┐
│ Promise.all([promise1, promise2, promise3])              │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  promise1: ✅ resolve → sucess                          │
│  promise2: ❌ reject → ERROR                            │
│  promise3: ⚠️ (nunca executa)                           │
│                                                          │
│  Resultado: Toda a Promise.all falha                    │
│  Efeito: promise3 recebe "sibling errored"              │
│                                                          │
└─────────────────────────────────────────────────────────┘

Isto é o comportamento CORRETO do Promise.all:
- Não executa promises adicionais se uma falha
- Falha rápido (fail-fast)
- Previne cascata de erros

═════════════════════════════════════════════════════════════════════════════
  CHECKLIST: Como Evitar o Erro
═════════════════════════════════════════════════════════════════════════════

Antes de usar Promise.all:

  [ ] Todos os recursos existem?
      └─ ✅ Use Glob para garantir

  [ ] Todos os paths têm quotes? (Windows)
      └─ ✅ "C:\Users\..." ao invés de C:\Users\...

  [ ] Todos os paths são relativos? (Preferível)
      └─ ✅ ./src ao invés de C:\...

  [ ] Há tratamento de erro?
      └─ ✅ .catch() ou try/catch

  [ ] Há validação pré-paralelo?
      └─ ✅ Glob/Grep/Read com limit antes
