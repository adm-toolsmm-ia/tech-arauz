### Category 4: KPI & Analytics (5 queries)

**Query 4.1: Project Status KPI**
```sql
SELECT
  COUNT(*) as total_projects,
  SUM(CASE WHEN status = 'active' THEN 1 ELSE 0 END) as active,
  SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) as completed,
  SUM(CASE WHEN status = 'on_hold' THEN 1 ELSE 0 END) as on_hold
FROM projects
WHERE tenant_id = $1;
```
**Baseline:** ~70ms | **Target:** <100ms | **Index:** FK index on tenant_id

---

**Query 4.2: Delivery On-Time Rate**
```sql
SELECT
  COUNT(*) as total_deliverables,
  SUM(CASE WHEN actual_date <= scheduled_date THEN 1 ELSE 0 END) as on_time,
  ROUND(100.0 * SUM(CASE WHEN actual_date <= scheduled_date THEN 1 ELSE 0 END) / COUNT(*), 2) as on_time_rate
FROM schedules
WHERE project_id IN (SELECT id FROM projects WHERE tenant_id = $1)
  AND actual_date IS NOT NULL;
```
**Baseline:** ~190ms | **Target:** <150ms | **Index:** idx_schedules_project_deliverable

---

**Query 4.3: Team Workload Distribution**
```sql
SELECT owner_id, COUNT(*) as assigned_count,
  SUM(CASE WHEN status IN ('active', 'in_progress') THEN 1 ELSE 0 END) as active_count
FROM projects
WHERE tenant_id = $1 AND owner_id IS NOT NULL
GROUP BY owner_id
ORDER BY assigned_count DESC;
```
**Baseline:** ~95ms | **Target:** <100ms | **Index:** FK indexes

---

**Query 4.4: Monthly Activity Trend**
```sql
SELECT DATE_TRUNC('month', created_at)::DATE as month,
  COUNT(*) as new_projects,
  COUNT(DISTINCT owner_id) as active_owners
FROM projects
WHERE tenant_id = $1 AND created_at > NOW() - INTERVAL '12 months'
GROUP BY DATE_TRUNC('month', created_at)
ORDER BY month DESC;
```
**Baseline:** ~110ms | **Target:** <100ms | **Index:** FK indexes

---

**Query 4.5: Bottleneck Analysis (Longest-Running Schedules)**
```sql
SELECT p.name as project, s.deliverable_id,
  AGE(s.scheduled_date, p.created_at) as project_age_at_schedule,
  CASE WHEN s.actual_date IS NULL THEN AGE(NOW(), s.scheduled_date)
    ELSE AGE(s.actual_date, s.scheduled_date) END as duration
FROM projects p
JOIN schedules s ON p.id = s.project_id
WHERE p.tenant_id = $1
ORDER BY duration DESC
LIMIT 20;
```
**Baseline:** ~210ms | **Target:** <150ms | **Index:** Multiple FK indexes
