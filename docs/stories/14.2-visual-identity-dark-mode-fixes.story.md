## Context

**Prior Work (Story 14.1):**
- Extracted design tokens from brand assets ✅
- Implemented Tailwind color system ✅
- Login page structure complete ✅
- **BUT:** Dark mode has contrast issues + login lacks brand orange

**Quality Gate Findings:**
- Issue #1: Card titles invisible in dark mode (1.5:1 contrast vs 4.5:1 required)
- Issue #2: Secondary text unreadable in dark mode (text-foreground/85 too weak)
- Issue #3: Alert badges invisible (bg-amber-900/30 nearly transparent)
- Issue #4: Login logo is white, not orange (requirement: "logo laranja mais evidente")
- Issue #5: Pattern too subtle (0.18 opacity = ghost)
- Issue #6: Form panel has no visual connection to hero panel
- Issue #7: Input focus ring green instead of orange (inconsistent with button)

**Root Cause:**
- Design system `--foreground` value works in light mode but insufficient in dark mode when combined with opacity reducers
- Login implementation missed "brand orange on hero panel" requirement
- Form inputs use primary color (green) instead of accent color (orange)
