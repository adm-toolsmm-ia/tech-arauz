## Objetivo

Criar dashboard 360° na página de detalhes de agentes com métricas de uso (runs, sucesso, latência, custos), gráficos de execução, e tabs adicionais para Ferramentas e Deployments, reusando componentes existentes (BudgetGauge, KPICard, Recharts).

---

## Como Usuário

Como gerenciador de agentes AI,
quero visualizar um dashboard completo com estatísticas de uso (últimos 7, 30 ou 90 dias), gráficos de execução, e ferramentas/deployments vinculados,
para que eu possa monitorar saúde, custo e configuração de cada agente em um único lugar.

## Critérios de Aceite

### 1. Backend Route GET /api/agents/[id]/metrics

- [ ] **Criado `src/app/api/agents/[id]/metrics/route.ts`**
  - Método: GET
  - Query params: `dateRange` (7d | 30d | 90d, default: 7d)
  - Lógica:
    1. Extrai `dateRange` de query params
    2. Calcula `startDate = today - X days`
    3. Query direto Supabase:
       - `SELECT * FROM agent_usage_daily WHERE agent_id = X AND date >= startDate ORDER BY date ASC`
       - `SELECT * FROM agent_deployments WHERE agent_id = X ORDER BY deployed_at DESC LIMIT 10`
    4. Calcula agregações: `runs_total`, `success_rate`, `avg_latency_ms`, `total_cost_usd`
  - Response format:
    ```json
    {
      "runs_total": 150,
      "success_rate": 94.5,
      "avg_latency_ms": 1250,
      "total_cost_usd": 12.35,
      "daily_data": [
        { "date": "2026-02-25", "runs": 10, "successful": 9, "failed": 1, "cost_usd": 0.15, "avg_latency_ms": 1200 },
        ...
      ],
      "deployments": [
        { "id": "dep-1", "status": "active", "deployed_at": "2026-02-20T10:00:00Z", "version": "1.0.0" },
        ...
      ]
    }
    ```
  - Error handling: 401 (Unauthorized), 404 (Agent not found), 500 (Server Error)
  - Não passa pelo FastAPI — padrão do módulo de projetos

### 2. Componente AgentMetrics360

- [ ] **Criado `src/components/agents/AgentMetrics360.tsx`**
  - Props: `{ agentId: string }`
  - Fetch: GET `/api/agents/[agentId]/metrics?dateRange={selected}`
  - State:
    - `selectedDateRange: '7d' | '30d' | '90d'` (default: '7d')
    - `data: MetricsResponse | null`
    - `loading: boolean`
    - `error: Error | null`
  - UI Layout:
    - **Row 1 (Period Selector)**: Botões/toggle para 7d, 30d, 90d (alinhado à direita)
    - **Row 2 (4 KPI Cards)**: Grid de 4 colunas
      - Card 1: "Total Runs" — exibe `runs_total` com ícone play/activity
      - Card 2: "Success Rate" — exibe `success_rate` % com ícone check
      - Card 3: "Avg Latency" — exibe `avg_latency_ms` ms com ícone clock
      - Card 4: "Total Cost" — exibe `total_cost_usd` USD com ícone dollar
    - **Row 3 (Charts)**:
      - Chart A (50% width): RunsChart — Recharts BarChart com 2 series (successful, failed) por dia
        - X-axis: Data (formato DD/MM)
        - Y-axis: Número de runs
        - Legenda: Successful (cor verde), Failed (cor vermelha)
      - Chart B (50% width): BudgetGauge reutilizado
        - Passa `budget_limit_usd` e `budget_spent_usd` do agente
    - **Row 4 (Cost Over Time)**: CostByDayChart — Recharts AreaChart
      - X-axis: Data (formato DD/MM)
      - Y-axis: Custo USD
      - Area: Gradiente (verde → mais claro)
      - Showlegend: true
  - Loading state: Skeleton loaders para cada card/chart
  - Error state: Toast error + fallback message

- [ ] **KPI Card Component (se não existir, criar `src/components/agents/KPICard.tsx`)**
  - Props: `{ label: string, value: string | number, icon: ReactNode, unit?: string }`
  - Layout: Ícone à esquerda, label + value centralizados
  - Styling: Padrão do projeto (bg-card, border, padding)

- [ ] **Charts Components**
  - **RunsChart**: Recharts BarChart com dados de `daily_data`
  - **CostByDayChart**: Recharts AreaChart com dados de `daily_data`
  - Ambos: Responsivos, sem hardcoding de dimensões

describe('AgentMetrics360', () => {
  it('renders 4 KPI cards with correct values', async () => {
    global.fetch = jest.fn(() =>
      Promise.resolve({
        ok: true,
        json: () =>
          Promise.resolve({
            runs_total: 150,
            success_rate: 94.5,
            avg_latency_ms: 1250,
            total_cost_usd: 12.35,
            daily_data: [],
          }),
      })
    );
    render(<AgentMetrics360 agentId="agent-1" />);
    await waitFor(() => {
      expect(screen.getByText('Total Runs')).toBeInTheDocument();
      expect(screen.getByText('150')).toBeInTheDocument();
      expect(screen.getByText('Success Rate')).toBeInTheDocument();
      expect(screen.getByText(/94\.5%/)).toBeInTheDocument();
    });
  });

  it('switches date range on button click', async () => {
    global.fetch = jest.fn((url) => {
      if (url.includes('dateRange=30d')) {
        return Promise.resolve({
          ok: true,
          json: () =>
            Promise.resolve({
              runs_total: 500,
              success_rate: 92.0,
              avg_latency_ms: 1300,
              total_cost_usd: 35.50,
              daily_data: [],
            }),
        });
      }
    });
    render(<AgentMetrics360 agentId="agent-1" />);
    await userEvent.click(screen.getByRole('button', { name: '30d' }));
    await waitFor(() => {
      expect(screen.getByText('500')).toBeInTheDocument();
    });
  });

  it('renders RunsChart with daily data', async () => {
    const dailyData = [
      { date: '2026-02-25', runs: 10, successful: 9, failed: 1 },
      { date: '2026-02-26', runs: 15, successful: 15, failed: 0 },
    ];
    global.fetch = jest.fn(() =>
      Promise.resolve({
        ok: true,
        json: () =>
          Promise.resolve({
            runs_total: 25,
            success_rate: 96.0,
            avg_latency_ms: 1200,
            total_cost_usd: 0.50,
            daily_data: dailyData,
          }),
      })
    );
    render(<AgentMetrics360 agentId="agent-1" />);
    await waitFor(() => {
      // Verify BarChart rendered (Recharts renders in SVG)
      const charts = screen.getAllByRole('img');
      expect(charts.length).toBeGreaterThan(0);
    });
  });

  it('displays loading skeleton initially', () => {
    global.fetch = jest.fn(() => new Promise(() => {})); // Never resolves
    render(<AgentMetrics360 agentId="agent-1" />);
    expect(screen.getByTestId('skeleton-kpi')).toBeInTheDocument();
  });

  it('displays error toast on fetch failure', async () => {
    global.fetch = jest.fn(() =>
      Promise.reject(new Error('Network error'))
    );
    render(<AgentMetrics360 agentId="agent-1" />);
    await waitFor(() => {
      expect(toast.error).toHaveBeenCalled();
    });
  });
});
