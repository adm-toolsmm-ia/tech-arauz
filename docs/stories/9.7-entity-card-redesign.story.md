## Notas Técnicas

### AreasCardView Layout

```typescript
// Estrutura de card rico
<Card className="hover:shadow-md transition-shadow">
  <CardContent className="p-4">
    {/* Cabeçalho */}
    <div className="flex justify-between items-start mb-2">
      <h3 className="font-semibold text-lg">{area.name}</h3>
      {statusBadge && <Badge>{status}</Badge>}
    </div>

    {/* Descrição */}
    <p className="text-sm text-muted-foreground line-clamp-2 mb-3">
      {area.description}
    </p>

    {/* Meta informações */}
    <div className="flex gap-4 text-sm text-muted-foreground mb-3">
      <div className="flex items-center gap-1">
        <Network size={16} className="text-primary" />
        <span>{area.nuclei_count} núcleos</span>
      </div>
    </div>

    {/* Roles badges */}
    <div className="flex gap-1 flex-wrap">
      {area.responsible_roles?.slice(0, 2).map(role => (
        <Badge key={role} variant="secondary">{role}</Badge>
      ))}
      {area.responsible_roles?.length > 2 && (
        <Badge variant="outline">+{area.responsible_roles.length - 2}</Badge>
      )}
    </div>
  </CardContent>
</Card>
```

### ProcessCard Component

```typescript
interface ProcessCardProps {
  process: OrgProcess;
  nucleusName?: string; // Para contexto
  areaName?: string;
  onClick?: () => void;
}

export function ProcessCard({ process, nucleusName, areaName, onClick }: ProcessCardProps) {
  return (
    <Card className="hover:shadow-md transition-shadow cursor-pointer" onClick={onClick}>
      <CardContent className="p-4">
        <h3 className="font-semibold mb-2">{process.name}</h3>

        {/* Badges contexto */}
        <div className="flex gap-2 mb-2 flex-wrap">
          {areaName && <Badge variant="outline">{areaName}</Badge>}
          {nucleusName && <Badge variant="outline">{nucleusName}</Badge>}
        </div>

        {/* Descrição */}
        <p className="text-sm text-muted-foreground line-clamp-2 mb-3">
          {process.description}
        </p>

        {/* Meta */}
        <div className="flex gap-4 text-sm">
          <div className="flex items-center gap-1">
            <ArrowDown size={14} className="text-blue-600" />
            <span>{process.inputs_count}</span>
          </div>
          <div className="flex items-center gap-1">
            <ArrowUp size={14} className="text-green-600" />
            <span>{process.outputs_count}</span>
          </div>
        </div>
      </CardContent>
    </Card>
  );
}
```

## Observações

Cards ricos exibem **mais contexto** do que cards genéricos (Story 9.1 OrgEntityCard). Diferença:
- **OrgEntityCard:** genérico, usado dentro de cockpits (AreaCockpit, NucleusCockpit)
- **AreasCardView, NucleosCardView, ProcessCard:** ricos, usado em listagens standalone

Padrão responsivo usa Shadcn grid classes (grid-cols-1, sm:grid-cols-2, lg:grid-cols-3).

Icons direcional para inputs/outputs (↓ / ↑) mantém consistência com InputOutputList (Story 9.1).
